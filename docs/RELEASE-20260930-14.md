# FIX14 — PDF upload feedback and document-grounded answers

Upload now reveals the conversation immediately and displays file receipt/reading status. Successful reading automatically returns one summary with figures from the current PDF. The legacy AI Executive wrapper is removed from every bot response.

Repeated uploads are detected by SHA-256 of the file bytes in HTTPS browsers; an in-progress upload with matching name/size/lastModified is not started again. A metadata fallback is used only where Web Crypto is unavailable. Previously parsed data is reused with an explicit notice. New chat/account changes still clear the document library.

Explicit PDF questions and financial follow-ups after upload bypass the live multi-intent analysis pipeline. Missing PDF values are not filled with simulation defaults. Comparisons show only matching known fields and do not equate ROI on property with ROI on equity. The feasibility parser now recognizes the exported four-column KPI table and the specific cashflow-after-mortgage label.
