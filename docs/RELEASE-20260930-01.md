## Installazione in ordine

1. In Firebase Console del progetto, Firestore Database → Regole: sostituire il contenuto con firestore.rules della patch e pubblicare. Non eliminare documenti o collezioni.
2. Estrarre lo ZIP FIX. Copiare tutti i file nella radice del repository GitHub mantenendo le cartelle e sostituendo le versioni omonime. Non caricare lo ZIP come singolo file e non creare un’ulteriore cartella rendimentobb-main.
3. Attendere il deployment Vercel Ready. Production deve usare chiave e webhook secret live. La branch stripe-sandbox-test deve usare chiave e secret test, prezzi test e BASE_URL della sandbox.
4. La sandbox riconosciuta è rendimentobb-git-stripe-sandbox-test-dominibus-projects.vercel.app; localhost è sandbox per sviluppo. Altri hostname hanno il comportamento live: aggiungere un alias test solo esplicitamente in js/account-plan.js, mai dedurlo da qualunque dominio vercel.app.
5. Ricaricare le pagine aperte con Ctrl+F5. Per il giro tra account usare Logout e login normale.

L’account b&b@test.com, se ha soltanto una sessione cs_test_, diventerà Free sul sito pubblico e manterrà l’annuale nella sandbox. È la separazione corretta dei diritti, non la perdita di un abbonamento reale. Controllare in Stripe il tipo di sessione se il comportamento diverge. Non condividere chiavi/password in chat.
