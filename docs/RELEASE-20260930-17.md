# FIX17 — Focused PDF answers and uniform chatbot formatting

PDF upload returns a compact data summary. Interpretation is a separate explanation of the recognized ROI, cash flow and financing assumptions. Single-metric questions (ROI, cash flow, risk, mortgage, revenue, equity, price, occupancy) return focused answers, not repeated summaries. Return-on-equity calculations require explicit ROI basis evidence; missing basis is stated. The parser now recognizes the report cashflow-after-mortgage label, assumed rate and annual loan payments. Derived monthly cash flow and financing ratio are labeled as calculations.

After upload, default actions name the active PDF. ROI, Cashflow, Risk and Worth it requests remain with that document and do not generate live-simulation score, occupancy or market benchmarks. Completeness answers recognize explicit after-mortgage cash-flow evidence. Clearing the document restores ordinary action labels.

All 44 chatbot JavaScript files were checked for syntax and rendering ownership: only chatbot-ui.js and chatbot-attachments.js directly create DOM content. The shared message renderer now formats all response sources with safe inline bold, compact paragraphs/headings and separate source notes. Default suggestions and contextual/action buttons share scoped styling. CSS is versioned along with scripts to prevent stale styles. Existing financial/PMS/support logic outside the PDF path is preserved; this release does not claim that all remaining conversational intents are newly intelligent or audited for content accuracy.
